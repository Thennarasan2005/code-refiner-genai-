# CodeRefine Pro 🎓

AI-powered code review platform with animated AI teacher,
audio briefings and live chalkboard error reveal.

## 🚀 Live Demo
https://n4lzc6bappoteboswyyzxfy.streamlit.app

## ✨ Features
- Paste buggy code → instant senior-architect analysis
- Animated SVG teacher with lip-sync & chalkboard
- Audio explanation via gTTS
- Cyberpunk dark UI

## 🛠️ Tech Stack
- Python + Streamlit
- Qwen2.5-Coder-32B (HuggingFace)
- gTTS (Google Text-to-Speech)
- Custom SVG + JavaScript

## ⚙️ Setup
1. Clone the repo
2. pip install -r requirements.txt
3. Add HF_TOKEN to .streamlit/secrets.toml
4. streamlit run app.py
